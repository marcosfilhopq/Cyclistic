# Estudo de Caso Google: Cyclistic Bike-Share 🚲

Este repositório contém a minha análise para o **Estudo de Caso 1** do Certificado Profissional de Análise de Dados do Google (Google Data Analytics Professional Certificate). 

A empresa fictícia deste estudo de caso é a **Cyclistic**, uma empresa de compartilhamento de bicicletas em Chicago. O objetivo principal da análise é entender como os membros anuais e os ciclistas casuais usam as bicicletas de forma diferente, com o intuito de direcionar uma nova estratégia de marketing para converter clientes casuais em membros anuais.

## 📁 Fonte de Dados

Devido ao tamanho elevado dos arquivos de dados (que ultrapassam o limite do GitHub), todos os arquivos brutos estão armazenados de forma pública e acessível no Kaggle.

🔗 **[Clique aqui para acessar e baixar o Dataset no Kaggle](https://www.kaggle.com/datasets/marcosfilho12/google-casestudy1-cyclist)**

*(Os dados originais foram disponibilizados pela Motivate International Inc. sob licença e foram processados para fins educacionais deste estudo de caso).*

## 🚀 Como executar o projeto localmente

1. Clone este repositório no seu computador.
2. Acesse o link do Kaggle acima e faça o download do Dataset.
3. Extraia/coloque os arquivos de dados na mesma pasta do projeto (eles serão ignorados pelo `.gitignore` para evitar envio acidental).
4. Execute os scripts em Python (`analise.py` e `visualizacao.py`) para reproduzir as análises e gerar os gráficos.

## 🛠️ Tecnologias Utilizadas
* Python (Pandas, Matplotlib/Seaborn)
* SQL / SQLite (para processamento inicial de tabelas grandes)
* Git e GitHub
